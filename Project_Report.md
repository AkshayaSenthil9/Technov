## Part C – Website Design
The website contains these major sections:
1. **Home** – introduces TechNova 2026 and provides a Register Now button.
2. **Event Information** – displays date, time, venue, description, schedule and participation benefits.
3. **Registration** – contains a complete participant registration form.
4. **Contact** – provides organizer and institution information.

Technologies used: HTML5, CSS3 and JavaScript.

## Part D – Registration Form
The form collects:
- Participant Name
- Register Number
- Department / Organization
- Email Address
- Mobile Number
- Year of Study
- Event Selection

## Part E – Form Validation
JavaScript implements:
1. Mandatory-field validation.
2. Email-format validation.
3. Ten-digit mobile-number validation.
4. Selection validation for year and event.
5. Error-message display.
6. Prevention of incomplete submission.
7. Registration-success message after valid submission.

## Part G – Registration Data Management
The project demonstrates **JavaScript localStorage** as a sample data-management method. After successful validation, registration details are stored in the browser under the key `technovaRegistrations`. This demonstrates collecting, organizing and retaining registration records for the prototype. A production website should use secure server-side storage and proper privacy controls instead of browser-only storage.

**Scenario:** Students need to register for a college technical symposium.

- Event Requirement: Collect registrations for TechNova 2026.
- Participant Requirement: Students need to submit identity, department, contact and event-selection details.
- Website Features: Home page, event details, schedule, registration form, validation, confirmation and contact section.

- Data Management: Browser localStorage for the prototype.
- Expected Output: A valid participant receives a registration-success message and the registration record is stored locally.
